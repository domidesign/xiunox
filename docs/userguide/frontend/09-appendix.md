### 验证码机制

| 场景 | 验证码标识 | 说明 |
|------|-----------|------|
| 登录 | login | 登录表单验证码 |
| 注册 | register | 注册表单验证码 |
| 发帖/回复 | post | 发帖和回复表单验证码 |
| 找回密码 | resetpw | 找回密码表单验证码 |

- 验证码是否显示由后台安全配置控制
- 每次表单提交后验证码自动刷新
- 点击验证码图片可手动刷新
- 验证码错误（code -1001）在验证码行内显示错误提示

### 错误码说明

| 错误码 | 说明 |
|--------|------|
| -1001 | 验证码错误 |
| -1002 | 频率限制/操作过于频繁 |
| -1003 | 账号锁定 |

### 交互特性

| 特性 | 说明 |
|------|------|
| htmx 局部刷新 | 列表排序、标签切换、搜索等操作无需整页重载 |
| 乐观更新 | 点赞、收藏、关注等操作即时反馈，服务端确认后自动修正 |
| CSRF 保护 | 所有 POST 表单包含 CSRF Token |
| 响应式布局 | 桌面端三栏布局，移动端自动隐藏侧边栏 |
| 代码高亮 | 帖子中的代码块使用 highlight.js 自动高亮（仅帖子详情页加载） |
| 图片灯箱 | 点击帖子图片打开全屏灯箱浏览 |
| 二维码 | 帖子详情页右侧显示当前页面二维码 |

### 权限说明

| 角色 | 权限 |
|------|------|
| 游客 | 浏览帖子、搜索（可能受限）、查看用户资料 |
| 普通用户 | 发帖、回复、点赞、收藏、关注、个人中心管理 |
| 版主 | 版主操作（删除/移动/置顶/加精/关闭/公告） |
| 管理员 | 所有版主权限 + 后台管理 |
