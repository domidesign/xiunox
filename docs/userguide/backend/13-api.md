## 十二、API

### 12.1 API 设置

![12.1 API 设置](images/13-api-01.png)

**路径**：`/admin/?api-settings.htm`

**功能说明**：配置 API 总开关、日志开关和应用管理。页面顶部含「文档」「设置」两个跳转按钮。

**配置项**
| 字段 | 类型 | 说明 |
|------|------|------|
| API 总开关 | switch | 是否启用 API 接口 |
| 日志开关 | switch | 是否记录 API 调用日志 |

**应用管理**：管理 API 应用列表，每个应用包含 AppID、名称、scope、限流、Capabilities、状态字段，支持应用创建。

---

### 12.2 API 文档

![12.2 API 文档](images/13-api-02.png)

**路径**：`/admin/?api-doc.htm`

**功能说明**：查看系统 API 接口文档，包含接口分组、参数说明、请求/响应示例。

#### 页面布局
- **左侧边栏**：按分组列出所有 API 接口，支持搜索过滤
- **右侧主区域**：显示 API 文档详情

#### 文档信息
| 项目 | 说明 |
|------|------|
| Base URL | `/api/v1/` |
| 响应格式 | JSON `{"code": 0, "msg": "ok", "data": {...}}` |
| 认证方式 | `Authorization: Bearer <token>` |
| Token 有效期 | 可配置 |

#### 每个接口包含
- 请求方法和路径
- 是否需要认证
- 参数列表（名称、类型、位置、是否必填、说明）
- 请求示例
- 响应示例
- 错误码列表
- 「试一试」按钮（跳转到 API 调试页面）

### 12.3 API 调试

![12.3 API 调试](images/13-api-03.png)

**路径**：`/admin/?api-debug.htm`

**功能说明**：在线调试 API 接口，发送请求并查看响应。

#### 页面布局
- **左侧**：请求历史和 Token 管理
- **右侧**：请求配置和响应结果

#### 请求配置
| 字段 | 类型 | 说明 |
|------|------|------|
| 请求方法 | select | GET / POST / PUT / DELETE |
| 接口路径 | text | API 路径（不含 `/api/v1/` 前缀） |
| Authorization Token | text | Bearer Token，可点击按钮自动填充或生成 |
| Request Body | textarea | JSON 格式的请求体（POST/PUT 时显示） |

#### 快捷接口
提供常用接口的快捷按钮：站点信息、帖子列表、版块列表、登录、发帖、回复列表、通知列表、搜索。

#### Token 管理
- 显示当前有效的 API Token 列表（UID、Token、过期时间）
- 支持撤销 Token
- 支持生成新 Token

#### 响应区域
- 显示 HTTP 状态码和响应时间
- JSON 响应语法高亮显示
- 支持复制响应内容

#### 请求历史
- 保存在浏览器 localStorage 中（最近 20 条）
- 点击历史记录可快速加载对应的请求配置
- 支持清空历史
