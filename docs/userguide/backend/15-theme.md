## 十四、主题

### 14.1 主题设置

![14.1 主题设置](images/15-theme-01.png)

**路径**：`/admin/?theme-list.htm`

**功能说明**：配置站点的主题模式和品牌色。

#### 主题模式
- **明亮模式**（Light）：清新明亮的浅色主题
- **暗黑模式**（Dark）：深色主题
- 点击对应主题卡片即可设为默认主题

#### 品牌色
提供 5 种预设品牌色：
| 颜色 | HEX 值 |
|------|--------|
| 蓝色 | #2563eb |
| 绿色 | #16a34a |
| 紫色 | #9333ea |
| 红色 | #dc2626 |
| 橙色 | #ea580c |

点击色块即可切换品牌色，切换后实时生效。
