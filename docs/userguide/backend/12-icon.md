## 十一、图标预览

### 11.1 图标预览

![11.1 图标预览](images/12-icon-01.png)

**路径**：`/admin/?other-icon_preview.htm`

**功能说明**：浏览和搜索 Tabler Icons 图标库，点击图标可复制 HTML 代码。

#### 操作步骤
1. 在搜索框中输入图标名称进行过滤
2. 浏览图标网格
3. 点击图标自动复制 HTML 代码（如 `<i class="ti ti-home"></i>`）
4. 页面显示图标总数

#### 注意事项
- 图标名称格式为 `ti-` 前缀
- 完整图标库参考：https://tabler.io/icons
