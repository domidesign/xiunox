## 九、其他

### 9.1 缓存设置

![9.1 缓存设置](images/10-other-01.png)

**路径**：`/admin/?other-cache_setting.htm`

**功能说明**：配置缓存驱动和策略，查看缓存状态。

#### 缓存状态
页面顶部显示当前缓存状态：启用状态、驱动类型、连接状态、默认 TTL。

#### 配置项
| 字段 | 类型 | 说明 |
|------|------|------|
| 启用缓存 | switch | 是否启用缓存 |
| 缓存驱动 | radio | 可选驱动（如文件缓存、Redis、Memcached），不可用的驱动会显示原因 |
| 默认 TTL | number（秒） | 缓存默认过期时间，最小 60 秒 |
| 自动预热 | switch | 是否在缓存失效后自动预热 |

#### Redis 配置（选择 Redis 驱动时显示）
| 字段 | 说明 |
|------|------|
| Host | Redis 服务器地址，默认 127.0.0.1 |
| Port | Redis 端口，默认 6379 |
| Password | Redis 密码 |
| Database | Redis 数据库编号（0-15） |

#### Memcached 配置（选择 Memcached 驱动时显示）
| 字段 | 说明 |
|------|------|
| Host | Memcached 服务器地址，默认 127.0.0.1 |
| Port | Memcached 端口，默认 11211 |

#### 测试连接
- 点击「测试连接」按钮可验证当前配置的缓存服务是否可连接

### 9.2 清理缓存

![9.2 清理缓存](images/10-other-02.png)

**路径**：`/admin/?other-cache.htm`

**功能说明**：手动清理各类缓存。

#### 操作项
| 字段 | 类型 | 说明 |
|------|------|------|
| 清理数据缓存 | switch | 清理系统数据缓存 |
| 清理模板缓存 | switch | 清理 `tmp/` 目录下的模板编译缓存 |
| 清理 OPcache | switch | 清理 PHP OPcache（如果 PHP 未启用 OPcache 则显示提示） |

#### 注意事项
- 修改模板后必须清理模板缓存（`tmp/` 目录）
- 修改 CSS 后需硬刷新浏览器（Ctrl+F5）

### 9.3 系统升级

![9.3 系统升级](images/10-other-03.png)

**路径**：`/admin/?upgrade.htm`

**功能说明**：执行系统版本升级，按步骤运行升级脚本。

#### 操作步骤
1. 查看当前版本和目标版本
2. 点击「开始升级」按钮
3. 系统会按顺序执行每个升级步骤
4. 每个步骤完成后显示执行结果（成功/失败）
5. 全部步骤完成后显示升级成功提示

#### 页面信息
- 显示当前版本号和目标版本号
- 列出所有升级步骤及其描述
- 每个步骤有独立的状态指示（等待/执行中/完成/失败）
- 失败时显示错误信息和重试按钮

#### 注意事项
- 升级前建议备份数据库
- 升级过程中请勿关闭页面
- 如有步骤失败，可点击重试按钮
- 改数据库需在后台「系统升级」页面添加升级项
