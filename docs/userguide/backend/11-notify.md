## 十、通知

### 10.1 通知列表

![10.1 通知列表](images/11-notify-01.png)

**路径**：`/admin/?notice-list.htm`

**功能说明**：管理系统通知和全局公告。页面包含两个子标签页。

#### 标签页 1：通知列表
- 显示系统通知列表
- 每条通知有删除按钮

#### 标签页 2：公告列表
- 首次切换时通过 AJAX 加载
- 显示全局公告列表
- 每条公告有删除按钮

---

### 10.2 发送通知

![10.2 发送通知](images/11-notify-02.png)

**路径**：`/admin/?notice-create.htm`

**功能说明**：发送系统通知或发布全局公告。页面包含两个子标签页。

#### 标签页 1：发送通知
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 接收者 UID | text | 是 | 接收通知的用户 UID |
| 通知内容 | textarea | 是 | 通知正文 |

#### 标签页 2：发布公告
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 图标 | text（图标选择器） | 否 | 公告图标，默认 ti-speakerphone |
| 公告内容 | textarea | 是 | 公告正文 |
| 链接 | text | 否 | 公告关联的 URL |
