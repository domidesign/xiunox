## 十三、插件

### 13.1 插件兼容检查

![13.1 插件兼容检查](images/14-plugin-01.png)

**路径**：`/admin/?plugin-scanner.htm`

**功能说明**：扫描插件的兼容性问题，检测代码中的潜在风险。

#### 操作步骤
1. 选择要扫描的插件（或扫描全部）
2. 选择严重程度过滤（全部/致命/警告/中等/信息）
3. 点击「开始扫描」
4. 查看扫描结果

#### 扫描结果
- 扫描摘要：扫描的插件数、问题总数、致命/警告数量
- 问题列表：插件名、版本、文件路径、行号、严重程度、匹配内容、建议

#### 规则详情
- 可展开查看所有扫描规则及其说明
- 每条规则显示类别、描述、严重程度和规则数量

#### 导出
- 支持导出 CSV 格式的扫描报告

### 13.2 插件管理

![13.2 插件管理](images/14-plugin-02.png)

**路径**：`/admin/?plugin-list.htm`

**功能说明**：管理插件的安装、启用、禁用和卸载。

#### 筛选和搜索
| 字段 | 类型 | 说明 |
|------|------|------|
| 类型 Tab | tab | 全部 / 插件 / 模板 |
| 关键词 | text | 搜索插件名称 |
| 状态 | select | 全部 / 已启用 / 已安装未启用 / 未安装 |

#### 插件卡片
每个插件以卡片形式展示，包含：
- 图标、名称、版本号
- 类型标签（插件/模板）
- 状态标签（已启用/已安装/未安装）
- 简介
- 操作按钮

#### 操作按钮
| 状态 | 可用操作 |
|------|----------|
| 未安装（已下载） | 安装（安装前会自动进行兼容性扫描） |
| 已安装且已启用 | 设置（如有）、禁用 |
| 已安装且未启用 | 启用、卸载 |
| 已安装 | 设置（如有）、卸载 |

#### 安装前扫描
- 点击安装按钮时，系统会自动进行兼容性扫描
- 扫描结果以弹窗形式展示
- 无问题：直接安装
- 有警告：可继续安装
- 有致命问题：需强制安装（有确认提示）

### 13.3 插件详情

![13.3 插件详情](images/14-plugin-03.png)

**路径**：`/admin/?plugin-read-{dir}.htm`

**功能说明**：查看插件的详细信息。

#### 显示信息
| 字段 | 说明 |
|------|------|
| 图标和名称 | 插件图标、名称、版本号 |
| 简介 | 插件功能描述 |
| 插件目录 | 插件的目录名 |
| BBS 版本 | 兼容的 BBS 版本 |

#### 操作按钮
根据插件状态显示：设置、安装、启用、禁用、卸载
