## 八、日志

### 8.1 积分日志

![8.1 积分日志](images/09-log-01.png)

**路径**：`/admin/?log-credits.htm`

**功能说明**：查看用户积分变动记录。

#### 统计概览
页面顶部显示四个统计卡片：今日变动次数、今日收入、今日支出、大额变动次数。

#### 筛选条件
| 字段 | 类型 | 说明 |
|------|------|------|
| UID | number | 按用户 ID 筛选 |
| 用户名 | text | 按用户名筛选 |
| 类型 | select | 按积分类型筛选 |
| 方向 | select | 全部 / 收入 / 支出 |
| IP | text | 按 IP 筛选 |
| 开始日期 | date | 起始日期 |
| 结束日期 | date | 截止日期 |

#### 日志字段
UID、用户名、类型、变动值（正数绿色/负数红色）、余额、原因、IP、时间
