# v1.0.5 - 2026-07-05

> **版本说明**: 缓存一致性与置顶帖显示修复为主 —— 修复审核/通知/回帖场景下缓存未失效的问题，置顶区不再受排序翻页影响，分页计数精确化

## 🐛 问题修复

### 缓存一致性（核心修复）
- **审核流程**：帖子/回帖审核通过或重新提交后，未清理版块与首页列表缓存 → 修复（`681bbbc`）
- **通知未读数**：notify 直接 SQL 更新 `unread_notices` 时未清理 user 缓存 → 修复
- **回帖更新**：`post_update` 未失效回帖列表缓存 → 修复
- **点赞/精华**：`post_like` / `thread_digest` 相关缓存联动修复

### 置顶帖与分页
- **置顶区始终显示**：置顶帖不再受排序、翻页影响，首页仅显示全局置顶（`thread_top_list.inc.htm` 新增）
- **分页计数精确**：`thread_count` 显式排除置顶帖（`top=0`）与已删除（`is_deleted=0`）
- **越界兜底**：批量操作后页码越界时自动跳转最后一页，避免空页

### 版块权限
- 新增 `post_find_by_uid_with_forum_access`：按版块访问权限过滤用户回帖列表
