# v1.1.1 更新日志 - 2026-07-16

> **版本说明**: 搜索体验优化 + 文档体系重建 —— 搜索支持可配置最小关键词长度与 ASCII 精确匹配、修复高亮 XSS；MIME 校验统一入口；文档拆分为插件开发/用户指南/插件 Skill 三套体系；新增三栏布局模板

## 🆕 新功能

### 搜索优化（`8da4930`）
- **关键词最小长度可配置**：`security_search_min_length`（默认 2）
- **ASCII 关键词走 LIKE 精确子串**：纯 ASCII 关键词跳过 FULLTEXT+ngram 全文索引，直接 LIKE 匹配，避免 ngram 分词对短英文词的干扰
- **LIKE 通配符转义**：`_` 和 `%` 转义，防止匹配范围爆炸
- **高亮 XSS 修复**：搜索高亮先 `esc_html` 转义再包裹 `<mark>` 标签
- **N+1 优化**：帖子详情批量预加载楼中楼点赞状态

### 文档体系重建（全新，`docs/` 三套）
- **插件开发文档**（`docs/plugindev/` 7 篇）：架构、插件结构、Hook 目录、API 速查、前端安全、AI 协作、运行时安全
- **用户指南**（`docs/userguide/` 前后台 40+ 篇）：后台 16 章 + 前台 9 章，覆盖全部功能操作
- **插件开发 Skill**（`docs/xiunox-plugin-dev/`）：SKILL.md + AI 规则/API 速查/Hook 目录，供 AI 协作开发
- **GitHub Issue 模板**（`.github/ISSUE_TEMPLATE/` 4 个）：bug / feature / question / config
