# v1.1.0 更新日志 - 2026-07-13

> **版本说明**: 审核流程升级 + 插件崩溃自愈 —— 新增审核忽略功能（不通知作者）、插件崩溃自动归因并禁用，在线升级改为 preflight 预检流程

## 🆕 新功能

### 审核忽略功能
- **AuditService 新增 ignore / batch_ignore 接口**（`a6bca3e`）：帖子/回帖/用户资料审核均支持忽略
- **后台审核页新增忽略按钮 + 批量忽略**：被忽略内容不通知作者
- 忽略项保留在审核列表（后续仍可通过/拒绝），不占未审核计数

### 插件崩溃自动禁用（自愈机制）
- **ErrorHandler 新增插件崩溃归因与自动禁用**：1 小时内同一插件崩溃 3 次自动禁用
- **归因策略**：`plugin/` 路径直接匹配 + `tmp/` 编译文件从行号往前查找 plugin-compile 注释定位插件
- 插件崩溃不再拖垮整个站点

## 🔧 重构与优化

- **EscapeService 增强**（`4544701`）：输出转义服务完善
- **安全审计增强**（AuditService）：审计覆盖范围扩大

- **前端 JS**：xiuno-modern.js 新增功能、xiuno.js 精简冗余
- **许可证更新**：版权链接指向更新
